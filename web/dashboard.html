🔬 How Lead Enrichment Works

1. Geocoding — Address → precise lat/lng via Google Maps API

2. Solar API — Google's satellite + ML analysis of the exact roof

3. Panel Matching — Picks the right system size for their usage

4. Financials — Calculates savings, ITC, payback, 25yr ROI

5. Lead Scoring — 5-factor score: sunshine, roof, bill, payback, ROI

6. Talking Points — Address-specific pitch points for your rep

🔌 API Endpoints

GET/POST /api/lead/enrich — Enrich a single address

POST /api/lead/batch — Enrich up to 10 addresses in parallel

POST /api/territory/scan — Scan a zip code territory

POST /api/territory/compare — Compare multiple zip codes

GET /api/lead/proposal — Generate full HTML proposal

POST /api/lead/canvass — Door-knock route optimizer

GET /api/stats — Aggregate pipeline stats from cache

GET /api/leads/history — All enriched leads, filterable

GET /api/territory/cached — List previous scans

GET /health — Service health check
