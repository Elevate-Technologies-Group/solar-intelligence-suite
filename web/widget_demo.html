Embeddable Widget

Solar Savings Calculator
Drop-in for any website

One script tag. Any website. Homeowners enter their address and instantly see personalized solar savings — all leads flow straight into your pipeline.

⚡ Quickstart (Floating Button)

<script src="http://localhost:8765/api/widget/embed.js" data-company="Elevate Solar" data-primary="%2316a34a" ></script>

🎛️ Embed Modes

🟢

Floating

Fixed button in corner. Pops open a modal. Works on any page — zero layout impact.

📦

Inline

Mounts inside a #target div. Perfect for landing pages and forms.

🔘

Button

Exposes SolarWidget.open() so you can trigger the modal from any button.

🔧 URL Parameters

company
Default: "Solar Intelligence"
Company name shown in the widget header.
tagline
Default: "Find out how much you could save"
Subtitle text below company name.
primary
Default: %2316a34a (green)
Accent color hex, URL-encoded. E.g. %23FF6B35 for orange.
mode
Default: floating
floating | inline | button
target
Default: (none)
CSS selector for inline mount, e.g. #solar-calculator
phone
Default: (none)
Rep phone number shown on thank-you screen.
rep
Default: (none)
Rep name shown on thank-you screen.
utm_source
Default: embed_widget
UTM source — passed through to lead record.

🔌 Widget API Endpoints

GET
/api/widget/embed.js
Serves the embeddable JavaScript widget. All URL params are forwarded as widget config.
GET
/api/widget/demo
This demo page — shows live widget with all three embed modes.
GET
/api/widget/snippet?company=...&primary=...&mode=...
Returns embed code as JSON — useful for dashboard snippet generator.
POST
/api/widget/submit
Receives lead submissions from the widget. Saves to pipeline DB + optionally Discord webhook. Body: {address, name, phone, email, monthly_bill, lead_score, …}
GET
/api/widget/leads
Returns all widget-captured leads sorted by submission time. Query: ?limit=50&priority=HOT
